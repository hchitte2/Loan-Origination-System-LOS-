# Handoff: Clearline product UI

## Overview
Finalised UI for **Clearline**, a demo loan origination system (spec: `PLAN.md` in the repo). Eight artboards / 27 frames covering Login, Pipeline board, Loan detail, Processor queue, Public borrower upload page, Dashboards, Superadmin Users + Activity, and a Component sheet, in light and dark. Today in every frame is **Sep 6, 2026**; all data is the sample fixture from `DESIGN-PROMPT.md`.

Suggested repo placement: unzip into `design/exports/2026-09-06/`, copy `reference/*.png` to `design/reference/`, fill the tokens into `src/app/globals.css`.

## About the design files
Everything in `html/` is a **design reference built in HTML**, not production code. Recreate it in the repo's stack: Next.js 16 App Router, Tailwind 4 (`@theme inline`), shadcn/ui, Lucide, Recharts 3, next-themes. Do not copy the HTML, the `support.js` runtime, or the inline styles. Use the PNGs in `reference/` as the visual target and `tokens.md` as the single source of design values. `html/data.js` holds the exact sample data (loans, needs list, pending documents, activity sentences) and can be transcribed into `src/db/seed.ts`.

## Fidelity
**High-fidelity.** Colours, type, spacing, copy, and states are final. Match pixel-for-pixel using shadcn primitives restyled through tokens (do not fork components).

## Design system (from `tokens.md`)
- Fonts: **Geist** 600 for display (wordmark, h1 20/28, KPI 28/32, borrower greeting 24/30); **Inter** for everything else (section title 15/22 600, body 14/20, control 13/18 500, caption 12/16, tag 11/14 500). `tabular-nums` on every number.
- One radius: **6 px**. 4 px spacing scale. Table rows 40 px (header 36 px, `muted` background). Board cards 12 px padding. Page gutter 24 px desktop / 16 px mobile. Sidebar 240 px. Buttons 32 px, inputs 36 px, pills 22 px, tags 20 px, nav items 36 px.
- Accent `primary` teal `#0f766e` (dark `#2aa393`), used only for primary buttons, active nav, links, focus ring, milestone tracker, upload-zone dashes.
- Semantic pills: text/icon in `success|warning|destructive`, background `color-mix(in oklab, <token> 12%, var(--card))`. Neutral pills (Requested, Waived, Needed, No longer needed): `muted` bg, `muted-foreground` text. Stage pills: bg `color-mix(chart-N 22%, card)`, text `foreground`, icon per stage.
- Every pill/tag pairs a Lucide icon with text; colour is never the only signal. Icons 16 px in pills/buttons/rows, 20 px in sidebar nav and empty states.
- Focus ring on every interactive element: `box-shadow: 0 0 0 2px var(--card), 0 0 0 4px var(--ring)`.
- Shadows: card `0 1px 2px rgba(0,0,0,.06)`, popover/dialog/toast `0 8px 24px rgba(0,0,0,.12)` (dark: .4 / .5).
- Dark mode is a token swap only. Amber impersonation banner `#fcd34d` with `#1c1400` text in **both** themes.
- Motion: 150 ms ease-out fades, ≤ 8 px slides. Under `prefers-reduced-motion` remove transitions, skeleton shimmer and spinner rotation.

### Icon mapping (Lucide)
Stages: Lead `circle`, Application `file-text`, Processing `loader`, Underwriting `search`, Conditional approval `list-checks`, Clear to close `check`, Funded `circle-check`, Withdrawn `circle-minus`, Denied `circle-x`.
Conditions: Requested/Needed `circle`, Received `clock`, Cleared/Accepted `circle-check`, Waived `circle-minus`, Needs another `circle-alert`. Review: Pending `clock`, Accepted `circle-check`, Rejected `circle-x`.
Attention tags: Needs review `file-text`, Stalled `flag`, Closing soon `calendar` (destructive tone). Nav: Dashboard `layout-dashboard`, Pipeline `kanban`, Queue `inbox`, Users `users`, Activity `activity`. Roles: Superadmin `shield`, Loan officer `briefcase`, Processor `clipboard-check`. Theme: `sun` / `moon` / `monitor`. Impersonation `eye`. Reset `rotate-ccw`. Wordmark mark: a stroke path `M2 14h8l3 4 9-12` (line breaking into a check), 2.5 stroke, `primary`.

## Interactions & behaviour
- Buttons say what happens; never "Submit"/"OK". Hover: primary darkens 12 % toward foreground; secondary/ghost → `muted`; destructive → 10 % tint. Disabled: 50 % opacity. Pending: spinning `loader` + "…ing" label; static under reduced motion.
- Dialogs: 40 % black scrim, popover shadow, `alertdialog` for confirms.
- Table rows and cards link to the loan; hover `muted`.
- Public page: upload → progress → "Received, under review"; rejection shows "Needs another: <reason>" and reopens the zone; waived items show "No longer needed" with no zone; e-consent shown once before first upload.
- Loading: skeletons matching layout, no spinners on primary surfaces. Empty states: icon + one sentence (+ one action where useful).
